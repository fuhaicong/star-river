# Star River Wander · 星河漫游

> 六一儿童节礼物 · 浪漫文艺风 · 交互式 WebGL 星空体验

## 概述

一个基于 Three.js 的交互式星空网页，手指/鼠标在星空中滑动产生流光拖尾，发现隐藏星座并浮现情话文案，发现全部星座后触发终章彩蛋。部署到 GitHub Pages 纯静态访问。

## 技术栈

- **Three.js**：WebGL 渲染、后处理（Bloom）、射线检测
- **自定义 Shader**：极光光幕、粒子着色
- **GSAP**：动画缓动（可选，也可纯 JS 动画）
- **部署**：GitHub Pages，单 HTML 文件 + JS 模块

## 配色

- 背景：`#0a0a14` 深空黑
- 渐变：深蓝紫 `#1a1a3e` → 星空蓝 `#0d1b3e`
- 星点：白 `#ffffff` / 浅蓝 `#aaccff` / 淡金 `#ffd700`
- 文案：白 + 淡金点缀

## 页面结构

```
星空背景层 → 极光光幕层 → 粒子层(交互) → HUD提示层 → 文案浮层
```

## 交互状态机

```
漫游模式 → 靠近引力点 → 星座汇聚动画 → 文案展示 → 继续漫游
                                                      ↓
                                         全部发现 → 终章彩蛋
```

## 核心模块

### 1. 星空背景层（StarfieldLayer）
- ~2000 粒子，3D 空间分布
- 缓慢漂移动画
- 鼠标附近粒子亮度提升

### 2. 拖尾系统（TrailSystem）
- 手指滑动产生光带
- Line 几何体 + 渐变透明度
- 1.5s 自动消散

### 3. 极光光幕（AuroraShader）
- 屏幕上方 Fragment Shader
- Simplex Noise 流动

### 4. 星座引力系统（ConstellationSystem）
- 5-7 个隐藏引力点
- 粒子被吸引 → 飞向星座轮廓 → 回弹缓动 → Bloom 亮起 → 文案淡入

### 5. 终章彩蛋（FinaleSystem）
- 全部星座发现后触发
- 所有粒子汇聚 → 星尘爆炸 → 文字浮现

### 6. 配置系统（config.js）
- 名字、星座文案全部可配

## 部署

- GitHub Pages 纯静态
- 构建产物：index.html + 内联/独立 JS
- 移动端适配：触摸交互 + 响应式
